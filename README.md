# DebarrasFrance

je veux créer ma startup dans le domaine du débarras, qui s'appel clearo. Le pilier principal du site serait une ia ou les clients peuvent directement upload leurs photo de ce qu'ils ont a débarasser et l'ia, entrainé au paravant, calcul directement le prix du débarras, fait un devis directement, le client peut tres bien aussi donner ses informations normalement pour un devis. Le but serait de faire une platform intermédiaire comme airbnb, enfaite le client fait son devis, donne sa localisation, et ça contact la personne qui fait du débarras dans le coin.
